# Gallery screenshots

Umbrel shows these on the app's store listing. Add three images named:

- `1.jpg` — the Leaderboard page
- `2.jpg` — the Trades / trade-flow page
- `3.jpg` — a Politician detail page

Recommended size ~1920×1080 (16:9), JPG or PNG. To capture them, run the app
locally (`docker compose up`), open each page, and screenshot it.
